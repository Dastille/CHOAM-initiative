# Contributing to CHOAM

This is a specification repo, not a factory.

**Useful PRs**

- Replace an uncited number with a sourced one.
- CAD / BOM / CNC files under CERN OHL-S v2.
- Accessibility audits of the 200–400 sq ft envelope.
- PIPEDA notes for the compute node.

**Not useful**

- Marketing language.
- Closed CAD.
- Facial-recognition “security” add-ons. That fights the spec.
