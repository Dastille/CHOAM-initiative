# CHOAM

**Codex for Housing, Off-Grid Architecture & Mobility**

Shelter is freedom. Homes must be open, modular, and enduring. No patent. No gatekeeper. No nation owns this.

CHOAM is a public standard for modular housing: affordable, off-grid capable, disability-accessible, and revenue-positive through solar net-metering and opt-in distributed compute.

## Read this first

The design document is [CHOAM-Idea_Draft.md](CHOAM-Idea_Draft.md) (v1.1). v1.0 shipped with leftover `<grok:render>` citation widgets that broke the markdown. Those are stripped. Claims remain a **blueprint**, not a procurement spec.

## What CHOAM specifies

| Layer | Intent | License posture |
| --- | --- | --- |
| Housing (200–400 sq ft modular) | WikiHouse-class CNC frames, plug-and-play utilities, ramps and adaptable layouts | CERN OHL-S v2 (hardware) |
| Energy | 5–10 kW solar + storage; net metering / VPP | CERN OHL-S v2 |
| Network + compute | Broadband node; opt-in BOINC-class research tasks | GPL-3.0 or AGPL-3.0 (this repo is AGPL-3.0) |
| Services | Food vouchers, health ties — local adapters | AGPL-3.0 for software |

This GitHub repo is licensed **AGPL-3.0**. Hardware derivatives should still carry CERN OHL-S v2 as described in the draft.

## Cost sketch (illustrative)

- Unit: **$50,000–$80,000**
- Factory: **$1–2B** at national scale
- Target ROI: **5–7 years** via solar + compute revenue
- Accessibility is a **requirement**, not an add-on

## Status

Design document only. No CAD, no BOM, no factory partners. Next useful commits: a 200 sq ft reference frame, a net-metering assumptions table, and a PIPEDA note for the compute node.
